## Loader

`LoadedGame.load()`/`loadGame()` accept bundle text or UTF-8 bytes. They validate schema, ABI/version contracts, semantic/presentation/content hashes and cross-file references before exposing data. Definitions are owned and frozen recursively. Routine lookup excludes replaced parser bodies; `createInitialMemory()` returns an independent copy. `createRandom()` creates an independent RNG from the bundle's initialization seed or an explicitly supplied oracle tape.

## World state

`WorldState.create(game)` builds the pre-GO image. Globals, ordered parent/child/sibling links, flags, short-name bytes and property data share the same authoritative memory. MOVE inserts first and unlinks the old position; REMOVE detaches. Cycle and invalid-object checks precede structural writes. All 32 attribute bits work, including the high signed bit.

GET/GETB/PUT/PUTB share big-endian storage, including unaligned word accesses that fit one allocation. Static segments, padding and protected header bytes cannot be written. Only header word 8 is writable. Pointer arithmetic and accesses reject overflow and crossing an allocation's bounds. Bounds are defined by the complete operation and numeric base address, including one-past endpoints; at an adjacent shared boundary the same address can belong to the preceding pointer range or following allocation. Reads/writes must fit wholly in a real allocation. There is no hidden pointer provenance in a 16-bit word. SRC-012 records this clarification of the earlier “one-past cannot be dereferenced” wording.

The property API supports defaults, raw addresses, lengths, descending NEXTP order and existing one/two-byte PUTP. PSEUDO-OBJECT retains its required ACTION-minus-five short-name storage. `validate()` checks protected memory, ordered-tree membership/cycles, property pointer/header/length invariants, explicit reference domains and the core HERE/PLAYER/WINNER/pronoun object globals. This is not yet full dynamic operand-domain inference or a complete engine-save validator.

Memory forks share 256-byte pages until a write. Both parent and child detach a shared page before mutation, including nested forks. `snapshot()`/`WorldState.restore()` own their bytes, check the semantic build hash and validate before exposing restored state. `worldHash()` hashes this world-only snapshot. These are not complete saves: execution frames, RNG, decisions and knowledge gates must be included by the later interpreter/checkpoint layer.

Ten tests cover initial source-built bytes and all object-parent links, ordered mutations, invalid cycles, every attribute bit, byte/word aliasing, globals, header/static/allocation guards, pointer boundaries, property defaults/layouts, independent forks and corrupted snapshots/references. The original-memory relocation audit remains independent evidence for initial values. WorldState alone remains pre-GO. The evaluator now runs GO and compares its output, all 251 object link/flag records and every global without an initial address/string/routine relocation against the original's first READ checkpoint. The input prompt belongs to the not-yet-run adapter and is excluded explicitly. Initial relocation values are independently covered by the phase 2 memory audit. ## Interpreter primitives

`numeric.ts` implements signed-word arithmetic, wrapping, truncating division, dividend-signed remainder, bitwise tests, equality and signed comparisons. Variable update/compare returns both the new word and predicate result; the continuation evaluator controls operand evaluation and assignment order. Short-circuit forms are deliberately not eager ALU operations.

`GameRandom` owns deterministic xorshift32 state. Zero reseeds to the configured seed; negative signed bounds reseed with their magnitude; positive bounds return 1..n using rejection sampling over xorshift32’s nonzero-word domain. `assertReplayComplete()` rejects an unused tape tail at conformance completion. Snapshots include seed/state, draw position, replay cursor and tape identity. Replay validates every range, including reseeds, and errors on mismatch/exhaustion without advancing state. Tests replay the existing area-barrow oracle tape, whose original RNG algorithm remains a separate reference setting. The engine's ordinary algorithm is not claimed to equal the original interpreter's MT19937.

`decodeZText` decodes compiler-emitted V3 short names and dictionary words with explicit word bounds. It handles alphabet shifts, punctuation, newlines and ASCII ZSCII escapes, and rejects unsupported abbreviations/malformed data. All 251 object short names match source metadata; all 689 dictionary encodings match the independent original-story decoder. General abbreviation-table execution is unnecessary for the emitted data image and remains unsupported.

Eight ALU/RNG tests and four text tests cover fixed vectors, signed boundaries, arithmetic errors, replay mismatch/restore/aliasing, original dictionary decoding and invalid text bounds/escapes. The headless boundary check continues to prohibit host I/O, clocks and ambient randomness.

## Continuation evaluator

`Interpreter` runs mapped IR with explicit routine frames, local words, per-frame operand stacks and expression/block activation cursors. Arguments evaluate left to right once; supplied optional zero skips the default. Defaults/AUX and block bindings initialize in source order. AND/OR/COND short-circuit and preserve deciding values. RETURN selects its compiled block/routine target; AGAIN retains that activation’s bindings; routine returns and RSTACK unwind nested blocks. APPLY zero returns zero after evaluating its arguments, and nonzero targets go through guarded runtime routine lookup.

The evaluator implements numeric, memory, object/property, output, RNG and VERIFY operations. Dictionary output reads encoded dictionary addresses; object output reads mutable short-name bytes. Direct PARSER calls suspend only from MAIN-LOOP-1; indirect adapter calls and removed routine IDs are rejected. Unsupported streams fail explicitly. There is no host I/O in this layer.

READ/SAVE/RESTORE/RESTART/QUIT retain an explicit suspended expression and its enclosing operand/call continuations. The low-level `resume()` accepts SAVE success/failure and RESTORE/RESTART failure. It rejects raw READ/parser results; the decision-only `answer()` adapter supplies READ buffers, and rejects successful session replacement operations until the lifecycle layer exists. It does not implement public host request IDs, epochs or revisions.

Each run/resume segment forks world memory and clones frames, stacks, cursors and RNG state. The structural world validator runs before publishing each boundary. An error discards unreturned output/random events and restores that complete execution state. Prior returned text and host suspensions remain committed. Step, call-depth, expression-stack, operand-stack and output limits bound execution; counters persist across suspensions. `world()` returns an independent fork. `inspect()` returns owned JSON-safe diagnostics, including the continuation and RNG cursor; it is **not** a validated external checkpoint/import format.

Twenty evaluator tests cover hand-written three-room execution, argument ordering/defaults, short circuits, recursive frames, block/routine AGAIN, nonlocal returns and operand stacks, dynamic calls, object/flag/memory operations, signed pointer offsets, output domains, host suspension/resumption, diagnostic ownership, checkpoint round-trips/rejection, budgets, rollback and original-story startup text/object/global comparison. The comparison deliberately stops before parser adaptation and does not claim full per-command conformance.

## Execution checkpoints

`checkpoint()` returns owned memory, frames/locals/operand stacks, execution-program identity, expression and block cursors, primitive wait, return value, RNG state/tape identity, configured limits and consumed budgets. `stateHash()` hashes that complete low-level state. `Interpreter.restore()` first checks a strict shape/resource schema, canonical JSON constraints, semantic build identity and frame relationships against the loaded IR. It validates expression cursors/operand counts, block ownership, activation indices, pending callee arguments and suspension identity, then independently validates world memory and RNG identity/state. It constructs a new instance, so rejected input cannot alter an existing execution.

Tests serialize/deserialize nested SAVE inside a call/block, restore an original-story parser suspension, resume the same future result, preserve RNG replay position and budgets, reject corrupted shapes/references/frames/static bytes/tape identities and verify failure leaves the original hash unchanged. This `zxr-interpreter-checkpoint-v1` format is an execution-core checkpoint, not the public boundary/primitive-save envelope. Public saves still need knowledge gates, lifecycle/protocol state, correlated host completions and the SAVE-success restoration rules.

## One-word READ decisions

`writeReadWord()` implements the V3 overwrite rule in an independent memory fork: preserve both capacity bytes; write lowercase text and a zero terminator; write count one, the relocated dictionary word, token length and text offset one; retain all unused text/parse tail bytes. Unknown words keep dictionary zero. It bounds-checks the declared capacities and rejects overlapping buffers. Failed writes cannot partially alter the supplied world.

`Interpreter.answer()` accepts YES/NO only in translated YES?, and RESTART/RESTORE/QUIT only in translated FINISH. It writes the original READ operands and resumes that expression transactionally. These are internal choices without public decision IDs; epoch/revision correlation remains the lifecycle layer’s responsibility. The translated routines select their own branches and host operations.

Seven tests cover exact buffer writes and unused tails, unknown words, malformed/capacity/protection/overlap errors, serialized YES? continuations, V-QUIT’s exact original prompt and NO response without a move, affirmative buffers against the original story, all FINISH host branches and repeated prompts after failure, and rollback/source diagnostics on a failed decision write.

## Completed turn loop (3.4)

`TurnLoop` starts translated GO and runs MAIN-LOOP-1 through the retained PARSER prologue to its actual fresh READ. Startup includes the original prompt. `execute(action)` resolves a complete structured choice and continues through translated checks, PERFORM, M-END and CLOCKER until the next fresh READ, decision READ or host primitive. No handwritten clock, room handler or verb replaces the source. The returned `TurnResolution` contains accepted action sequence, status, exact ordered text, move count, source-derived clock ticks for this segment, random events and the current execution boundary. This is the execution portion of the later public ActionResolution; it supplies no invented presentation events or unfiltered player observation.

The next fresh prologue runs before a result is published: actor WINNER/HERE/LIT reset at the source's original point, vehicle context stays intact, match counts clear and P-ITBL copies to P-OTBL. Prompts belong to the segment that produced them, so successive results match the original transcript without moving prompts between actions. The legacy low-level Interpreter still defaults to its pre-PARSER diagnostic boundary for parser-return/action-complete comparisons. `inputBoundary: 'read'` selects the integrated path and participates in validated checkpoints. Raw READ text submission is confined to standalone diagnostic fragments; integrated commands require structured actions.

The adapter supports ordinary zero/one/two-object actions, source noun/adjective spellings, global and nested scope, ALL and one-sided lists, pseudo features, actor TELL/command passes, puzzle speech and bound quoted actions. Missing explicit operands and exhausted ALL searches run the source GET-OBJECT missing-match arm; translated checks and dispatch decide refusals and mixed-list results. A surviving bare quoted direction takes the original direction fast path, preserving prior syntax/verb and remaining quote/count state. Ambiguity, identity mismatches, incompatible pseudo bindings, simultaneous multiplicity, orphan/reserve input and unbound multi-word command text are explicit action-language rejections/errors, not unfinished source-loop branches. They remain listed in the action contract and rules ledger; there is no free-text or speech-recognition input.

One accepted fresh choice gets one action sequence even across several source passes or a suspended YES?/FINISH or host primitive. Source decisions and primitive results resume the same command and budget. Ordinary actions are refused while one is pending. Late failures restore the last exposed boundary, including memory, RNG, frames, output, budgets and sequence; an already returned prompt or earlier segment remains committed. Diagnostic turn checkpoints round-trip startup, input, decisions and host boundaries, validate the startup continuation and never serve as public save envelopes.

Acceptance includes original-story comparisons for TAKE/DROP, two-object actions, LOOK, speech, directions, implicit taking, ALL with mixed results, robot inventory/movement/refusals and cage rescue, the bucket journey and M-END rise/disembark, and direct/indirect Tea Room pseudo features. The integrated runner compares exact text through the next prompt, syntax/parser tables and selected globals, every object link/flag, clock slots, moves, RNG position and restored checkpoints. Separate parser-return fixtures retain the detailed lexical/span comparisons. The source-extracted PERFORM fixture verifies all eight layers, first-nonzero stopping and nested restoration; fourteen V-WALK cases cover all five exit layouts. Decision/host suspension, late budget rollback, malformed requests/checkpoints, a surviving actor quotation reaching YES?, and a synthetic exhausted ALL search are also covered. REF-001 remains the explicitly bounded oracle detached-sibling exception. See [the action contract](action-plans.md).

Validation: 394 tests across 30 files, typecheck/build, all compiler/schema/bundle audits, the original source/binary audit, five-room output checks and all 75 twice-reproduced reference fixtures pass.
