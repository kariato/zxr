It retains the source game's MIT license; keep [ZORK-II-MIT.txt](ZORK-II-MIT.txt) with any distribution of this generated game data. Zork trademarks are not licensed by that notice.

Generate with `npm run world:record`; verify without writing with `npm run world:check`. Source locations in the JSON are relative to `reference/zork2/`. `reference/world-audit.json` records source hashes and comparisons against the release 63 / serial 860811 binary. `reference/world-spot-checks.json` records ten room and ten object source examples.

This is metadata-stage output: 86 rooms, 165 objects, 795 non-exit properties, 31 defaults and 220 retained exit declarations. Exit bytes, table/global allocations, string handles, routine logic, runtime memory and bundle packing are not generated yet. Read the top-level stage tag before using it. Startup mutations from GO have not been applied.
