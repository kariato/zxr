# Zork II scene directories

17 scene groups containing all 86 source rooms. These directories organize authoring work; grouping does not merge engine room identities or change approved plans and runtime bindings.

[Grouping rationale and production order](../../../../docs/scene-grouping-review.md)

Each scene directory contains its room directories and a scene README. Each room README links to source context, the original declaration, and available draft/approved plans. Put shared scene assets in the scene directory and room-specific work in the room directory. Generated context and existing plan paths are preserved.
