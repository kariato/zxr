# Untouched carousel hub shape

Direct Tencent Hunyuan output: 99,924 vertices, 199,868 triangles and 3,598,288 bytes. `carousel-hub-v1.glb` is unchanged pipeline output. The Blender project adds separate review cameras and lights without modifying imported vertices, faces or UVs.

Front/back geometry renders were inspected. The circular hall, eight radial stubs and west chamber survive, but the model is shallow. Some arch mouths are closed recesses or partially filled, and lateral entrances are less distinct than the others. Manual arch normalization, passage opening, crawl clearance and enclosing ceiling are needed. The numeral 8 remains a separate future detail.

Native inference units, no cleanup, scaling or runtime integration. Generation and Blender verification JSON record settings/hashes and preservation checks. Tencent license and notice apply.
