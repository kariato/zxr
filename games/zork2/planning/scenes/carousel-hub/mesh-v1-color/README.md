# Editable colored carousel hub

`carousel-hub-color-v1.blend` packs the concept and editable UV projection at 60 degrees. The sibling GLB embeds its color texture. The original Tencent vertices/faces are unchanged; verification JSON records preservation and source GLB hashes.

Single-reference projection is a draft color method, not multiview paint; side and rear surfaces can stretch and repeat. Existing closed/partial archways remain. Source movement, room lighting, high ceiling and numeral 8 require later assembly. The original shape and Tencent license/notice are in `../mesh-v1/`.
