# Lower ravine and cliff rooms

One ravine at multiple elevations, with an adjoining ruined hall and two cliff chambers. Share rock and stream scenery with the opening cavern where useful, but extend the model to provide the actual ledges, deep ford, climb and halls. Marble Hall's secret connection and the Tiny/Dreary shared door require state-controlled boundaries.
