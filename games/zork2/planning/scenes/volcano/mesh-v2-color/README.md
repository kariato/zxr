# Editable colored volcano draft

`volcano-color-v2.blend` contains the unchanged second Tencent shape with packed `concept-v2.png` and editable projected UVs. `volcano-color-v2.glb` embeds the texture. Single-reference projection provides draft colors; it is not learned multiview painting. Side/back surfaces can stretch or repeat the image. The input alpha is not used as a material transparency cutout.

`verification.json` records geometry preservation and confirms the source GLB remains unchanged. Source state, ledge clearances, chimney continuity and room separation remain manual work. Original uncolored mesh and Tencent license/notice are retained in `../mesh-v2/`.
