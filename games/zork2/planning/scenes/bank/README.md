# Bank

One bank architectural kit, mirrored teller/viewing wings, depository and office. High asset reuse, but magical walls and computed returns make a conventional continuous floor plan unsuitable. Small Room and Vault can be isolated scene cells using the same kit, reached through source-controlled transitions.
