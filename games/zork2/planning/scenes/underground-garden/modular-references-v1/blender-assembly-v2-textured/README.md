# Garden shell color preview

`garden-modular-textured-v2.blend` preserves all eight separately editable assets and adds a packed garden-only reference texture to the shell using a 35-degree UV projection. The seven props retain their original solid editable material colors. Geometry, placement and source assembly are unchanged.

The front and side previews are 3840 × 2160 JPGs. Front color aligns broadly with the garden concept. The side preview exposes substantial stretching on steep and hidden shell surfaces: this is a single-image projection draft, not a multiview texture repair. The separated props avoid the sculpture/gazebo image smearing present in the earlier fused garden attempts.

Verification checks source hash, unchanged geometry, eight independent transform roots and reopening the saved native file. The projected image is packed inside Blender. No runtime integration or GLB replacement is performed.
