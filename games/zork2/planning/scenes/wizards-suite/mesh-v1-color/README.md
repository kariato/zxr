# Editable colored suite

`wizards-suite-color-v1.blend` packs the concept image and editable single-reference projected UVs. The sibling GLB embeds the color texture. Vertex positions and faces remain unchanged, checked in `verification.json`, along with the source GLB hash.

Front/back colored renders were inspected. The front recalls the room concept; the back repeats room artwork and stretches across walls. This is a manual texture starting point, not multiview paint. Closed doorway recesses and fused furnishings remain in the source shape. The aquarium, guardian door/head, chalk pentagram, trophy exhibits and changing quarters furnishing are separate future assets.

Original geometry and Tencent license/notice remain in `../mesh-v1/`.
