# Draft presentation examples

These handwritten JSON examples exercise phase 6.1's scene-plan, asset-brief and label-set contracts. They are not approved art, generated models or runtime game rules. Room sizes, placement and material values are provisional. The formal garden is underground, consistent with its source description.

Run `npm run planning:check` to validate them, and `npm run schemas:check` to check their published schemas. See [phase 6](../../../../docs/phase-6.md) for coordinates, authority boundaries, provenance and the remaining review steps.
