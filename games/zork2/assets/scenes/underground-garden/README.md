# Compact runtime underground garden

`underground-garden-shared-v4.glb` supplies the shared scene for Garden North, Gazebo Room, Formal Garden and Topiary Room. The 2.89 MB model uses repeating 256px gravel and foliage textures, six separately placed hedge figures and a central textured gazebo. The cave panorama is loaded separately by the existing cached backdrop. Source room transitions and game rules are unchanged.

The editable source and 45°/45° preview are in [the shared-texture assembly](../../../planning/scenes/underground-garden/concept-top-down-v1/assembly-v4-shared-textures/). Hedge beds stand 1 metre above the gravel paths, with their figures resting on top. The gazebo entrance remains at its previous level. Bed outlines follow a reconstructed material grid and retain some stepped edges. Fine statue details and gazebo rails are simplified. Original larger assets remain available.

Run `tools/assets/garden-compact-runtime.py` with the local Blender Python environment to regenerate the runtime GLB, room origins, interaction layout and walking surfaces. Runtime grounds span approximately 56 by 37 metres, with paths at 1.5 m in scene coordinates. The gazebo is 4.6 metres wide and hedge figures are 2.1–2.4 metres tall, scaled independently of the grounds. The display slab is removed; a continuous cavern ground plane surrounds the beds. The overview uses a lower camera. Outdoor walking surfaces use the actual gravel triangles, excluding foliage beds. The gazebo uses a bounded interior floor sampled below the roof. Non-garden walking data is retained. The runtime file stays below 3,000,000 bytes; all three material images are embedded. `scene.json` records hashes and layout. Tencent notices remain in the existing license bundle.
