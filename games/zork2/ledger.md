# Zork II rules and differences ledger

The compatibility target is the pinned **release 63 / serial 860811** binary. Reference findings do not authorize gameplay changes. Keep `reference/zork2` unchanged.

| ID | Class | Evidence | Decision |
|---|---|---|---|
| SRC-001 | Source/build configuration | `gmain.zap` PERFORM contains the `PRSI=IT` guard from the PREDGEN variant in `gmain.zil`; its direct dispatch has no DD-APPLY wrapper. ZORK-NUMBER is 2 and Zork III-specific branches are absent. | Select the PREDGEN game-code variant and ZORK-NUMBER=2 for compatibility. |
| SRC-002 | Source/build metadata discrepancy | `zork2.zil` says `<ID 0>` when PREDGEN is assigned, but the supplied story identifies itself as release 63. The original build driver and command-line ID handling are unavailable. | Preserve the supplied story's release/serial and record the discrepancy. Do not label a future port's release-header difference as a gameplay bug or silently infer that PREDGEN was absent. |
| SRC-003 | Source inventory difference | The earlier line-based scan counted 441 routines and 24 I-* declarations. The phase 1 reader finds 456 routine forms including object comments/inactive branches, with all seventeen exclusions recorded in `reference/active-program.json`. `crufty.zil` is not inserted, and debug PERFORM/DD-APPLY is unselected. | Use the active manifest's 439 routines and 23 interrupts. Excluded source forms are not missing port routines. |
| SRC-004 | Permitted source redefinition | Shared `gverbs.zil` and game-specific `2actions.zil` both declare DUMMY. The entry sets local REDEFINE to true; assembly has one DUMMY slot with the game initializer. | Keep the later declaration and record the override. Reject duplicates when REDEFINE is false/unassigned. |
| SRC-005 | Source inventory correction | The reader finds 269 active syntax entries and 75 synonym forms; all syntax bytes and synonym dictionary roles match the assembly. The earlier 267/74 line counts missed forms nested inside compile-time conditions. | Use 269/75 as phase 2 vocabulary completion targets. |
| LANG-001 | Deliberate language scope | Zork II has fifteen DEFMACs and three DEFINE helpers. Seventeen definitions are selected; debug D-APPLY is unselected. TypeScript ports and definition guards cover all eighteen. | Defer a general MDL macro interpreter until a second game needs it. Reject unknown/altered macro programs rather than silently expanding by name. |
| REF-001 | Interpreter setting | Reference RNG is pinned MT19937/CPython integer seed 2; some death fixtures invoke the original `#random` verb. Restart and restore reset/restore reference RNG state. | Replay the logged ranges/results during conformance. Normal ZXR play may use its own owned RNG. Do not classify different normal RNG numbers as source-version differences. |
| REF-002 | Host setting | The headless runner suppresses the V3 status line and normalizes CR to LF; it keeps game text and prompt output. | Compare the recorded normal text. Rendering a status bar is a presenter concern. |

The opcode audit has no differing routine headers, opcode sequences, or decoded instruction offsets. It is not a rebuild or exhaustive comparison of every operand, property table, or string in the source. Twenty source/assembly spot checks and their checked anchors are in `reference/spot-checks.json`; details and limits are in `docs/reference-audit.md`.
